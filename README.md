# ARISE GYM - APK bauen (ca. 10 Minuten, ohne Android Studio)
1. Auf github.com kostenlos anmelden -> "New repository" (privat ist ok).
2. "uploading an existing file" -> den GESAMTEN entpackten Ordnerinhalt hineinziehen (auch den versteckten Ordner .github) -> Commit.
3. Reiter "Actions" -> "Build APK" -> der Bau startet automatisch (ca. 5-8 Min).
4. Fertigen Lauf oeffnen -> unten bei "Artifacts" -> "arise-gym-apk" herunterladen -> entpacken -> app-debug.apk aufs Samsung S23+ kopieren, antippen, "Aus dieser Quelle zulassen".
Beim ersten Start mit Internet laedt die App ca. 870 echte Uebungen (free-exercise-db) und speichert sie offline; die APK enthaelt sie ausserdem beim Bau.
